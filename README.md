# 🔍 PokeSearch – Pokémon Search App

A fun and interactive app that lets you search for any Pokémon using its **name** or **ID**. Get to know your favorite Pokémon's stats, abilities, and more through an intuitive interface powered by the PokeAPI.

> 🌐 **Live Demo**: [PokeSearch](https://dileepkumarrambarki.github.io/PokeSearch/)

---

## 📌 Project Overview

In this application:

- The user can search for Pokémon by **ID** or **Name**.
- Fetches real-time data from the Pokémon API.
- Displays detailed information such as:
  - 🏋️ Weight & Height  
  - 🏆 Ranking  
  - ⚔️ Attack Rate  
  - ❤️ HP Attack  
  - 🔥 Special Attack  
  - 🛡️ Defense  
  - ⚡ Speed

---

## 🛠️ Technologies Used

- ✅ **HTML** – Structure of the app  
- 🎨 **CSS** – Styling and layout  
- 📜 **JavaScript** – Logic & API integration  
- 🔗 [PokeAPI](https://pokeapi.co/) – Data source

---

## 🚀 How to Use

1. Visit the [live demo](https://dileepkumarrambarki.github.io/PokeSearch/)
2. Enter a **Pokémon name** (e.g., `pikachu`) or **ID** (e.g., `25`)
3. View its stats, image, and details
